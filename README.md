# Akella Lakshmi Aiswarya — AI Engineer Portfolio

A premium personal brand website for an AI & ML Engineer aspirant, built with pure HTML, CSS, and JavaScript. No frameworks, no dependencies — just clean, fast, production-ready code.

## Live Preview

Deploy to GitHub Pages or any static host and share your link.

---

## Features

- **AI-themed particle canvas** with mouse-reactive physics
- **Typing animation** cycling through AI specializations
- **Dark / Light mode toggle** with persistent theme
- **Sticky glassmorphism navbar** with scroll detection
- **Smooth scroll-reveal animations** for every section
- **Interactive skill filter** (All / Programming / Web Dev / AI & ML / Tools)
- **Animated skill bars** triggered on scroll
- **Counter animation** for achievement stats
- **Project cards** with glow effects and feature tags
- **Certification gallery** with hover glow
- **Vertical timeline** for career journey
- **Contact form** with simulated submission feedback
- **Back-to-top button**
- **Fully responsive** — mobile, tablet, desktop
- **GitHub Pages ready** — zero build step required

## Deploying to GitHub Pages

1. Push all files to a GitHub repository (e.g. `aishu104/portfolio`)
2. Go to **Settings → Pages**
3. Set source to **main branch / root**
4. Your site will be live at `https://aishu104.github.io/portfolio`
